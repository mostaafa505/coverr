# كفر برنت

أداة شخصية لتصميم جرابات الموبايل وتجهيز ملف الطباعة بالمقاس الحقيقي. بتشتغل على الكمبيوتر والموبايل والتابلت، ومفيش فيها حسابات ولا لوحة أدمن: كل حاجة بتتعمل في المتصفح بتاعك.

## بتعمل إيه

- **اختيار الموديل** من 402 موديل (بحث بالاسم أو الكود)، وتقدر تضيف موديل جديد بمقاسه أو تعدّل مقاس موديل موجود. التعديلات بتتحفظ على الجهاز.
- **محرر تصميم** بالملّيمتر: صور، نصوص عربي وإنجليزي، أشكال، خلفية، تقسيم كولاج، طبقات، تراجع وإعادة، محاذاة مغناطيسية، وتعديل ألوان الصورة.
- شغّال باللمس: سحب، تكبير وتدوير بإصبعين، وزر "معاينة" بيعرض الجراب بالفتحات.
- **حفظ تلقائي** للتصميم في المتصفح، لو قفلت الصفحة بالغلط ترجع تلاقيه.
- **فحص قبل الطباعة**: دقة الصور (DPI) على المقاس الفعلي، نص فوق فتحة الكاميرا، نص قريب من الحافة.

## ملفات التصدير

| الملف | الاستخدام |
|---|---|
| `…_PRINT.pdf` | ملف الطباعة: مقاس الصفحة = الجراب + الهامش + هامش علامات القص. الصورة 300 DPI بالضبط ومدموغة بملف ألوان sRGB. فيه TrimBox و BleedBox حقيقيين، وعلامات قص، ومعلومات الشغل في الهامش. |
| `…_CUT.svg` | خط القص والفتحات متجهات بوحدة الملّيمتر (1 وحدة = 1 مم). |
| `…_ART_300dpi.png` | نفس الصورة بدون علامات، ومكتوب فيها 300 DPI. |
| `…_WHITE_mask.png` | (UV / DTF) طبقة الحبر الأبيض: الأسود = مكان الحبر. |
| `…_PROOF.jpg` | صورة مراجعة بالعين فقط. |

خيارات في الـ PDF: قلب مرآة (سبلميشن / DTF)، خط القص كلون خاص `CutContour` في طبقة منفصلة (لماكينات Roland / Mimaki / Graphtec)، علامات تسجيل للقص الضوئي، ونسخة أصغر JPEG 95%.

**ملاحظات صريحة:**
- الملف **RGB (sRGB)** مش CMYK، وده الصح لأغلب RIP السبلميشن و DTF و UV اللي بتعمل التحويل بنفسها. الملف مش PDF/X.
- افتح الـ PDF واطبعه بمقاسه الحقيقي (100% / Actual size).

## ⚠️ مقاسات الموديلات

أبعاد الموديلات في `public/catalog.json` جاية مع المشروع، ومعظمها تقريبية ومش من ملفات مورّد. قبل ما تطبع كمية، قِس جراب فعلي وعدّل من القائمة (⋮) ← **ضبط مقاس الجراب**. الأرقام هنا مرجعها ركن خط القص العلوي الأيسر.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run typecheck
```

## النشر على Vercel

المشروع كله ملفات ثابتة + صفحات Next.js، مفيش سيرفر ولا قاعدة بيانات ولا متغيرات بيئة. ارفعه على GitHub واعمل Import في Vercel وخلاص.

## هيكل الكود

```
public/catalog.json          بيانات الموديلات والماركات
src/lib/design/              نماذج العناصر، الرسم (canvas)، الفلاتر، فحص الجودة
src/lib/export/              بناء الـ PDF (pdf-lib)، SVG، PNG، ZIP
src/components/studio/       الاستوديو: الكانفس، اللوحات، التصدير، اختيار الموديل
```

- كل الأبعاد في التصميم بالملّيمتر، ونقطة الأصل ركن خط القص العلوي الأيسر. الـ bleed بيدخل في السالب.
- نفس دالة الرسم بتستخدم للشاشة وللتصدير، فاللي بتشوفه هو اللي بيتطبع.
