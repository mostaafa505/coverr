# كفر برنت PRO | منصة طباعة جرابات الموبايل بمقاييس المصانع

تطبيق ويب متكامل واحترافي لتصميم وطباعة كفرات وجرابات الهواتف الذكية جاهزة 100% للإنتاج والقص الصناعي.

---

## 🌟 المميزات الرئيسية

### 1. قاعدة بيانات دقيقة للأجهزة بالملليمتر (mm)
- **لا مقاسات تقديرية أو وهمية:** إذا لم يكن للموديل قالب معتمد من المورّد، يُعلّم فوراً كـ **"غير متاح / يحتاج قالب"** ويُحجب تماماً عن المستخدمين لحمايتك من الأخطاء وتلف الخامات.
- دعم أنظمة التشغيل: **Android** و **Apple iOS**.
- دعم الماركات العالمية والمحلية: **Apple, Samsung, Xiaomi, Oppo, Realme, Infinix, Tecno, Huawei...**
- تسجيل الأكواد والأسماء البديلة للموديلات (مثال: `Redmi Note 13 = 2312DRA50C`).
- قوالب طباعة تخزن كـ JSON قابل للتعديل تشمل:
  * أبعاد مساحة الطباعة الفعلية (العرض × الارتفاع بالملليمتر).
  * نصف قطر تقويس الأركان (Corner Radius mm).
  * مناطق الفتحات (Cutouts): الكاميرات، الفلاش، البصمة، النوافذ والمستشعرات كإحداثيات X, Y مع العرض والارتفاع والشكل (دائرة / مستطيل مقوس / مسار).
  * مقدار الـ Bleed (افتراضي 3 مم) وهامش الأمان Safe Zone (3 مم للداخل).

---

### 2. محرر تصميم متقدم (Design Editor)
- **معاينة حقيقية للمقاس:** شبكة أبعاد بالملليمتر مع محاكاة دقيقة لشكل الجراب.
- **تنبيه فوري لدقة الصورة (DPI Real-time Check):**
  $$\text{DPI} = \frac{\text{Pixels}}{\text{mm} / 25.4}$$
  إذا كانت الدقة أقل من 300 DPI يظهر مؤشر فوري وتحذير ملون على الشاشة.
- **كشف التداخل مع الفتحات (Cutout Collision Detection):** فحص آلي فوري إذا كان أي نص أو عنصر مهم يقع تحت فتحة الكاميرا أو الفلاش أو خارج منطقة الأمان (Safe Zone).
- **إرشادات مرئية:**
  * منطقة الـ Bleed (3 مم) تُعرض بشفافية وإطار منقط ليفهم العميل أنها ستُقص.
  * فتحات الكاميرا مظللة بشبكة تحذير حمراء (Hatched Hazard Overlay) وأيقونات واضحة.
- **أدوات التصميم:**
  * رفع وتكبير وتصغير وتدوير وتغيير شفافية الصور.
  * فلاتر ألوان (أبيض وأسود، سيبيا).
  * إضافة نصوص بخطوط عربية (Cairo, Tajawal, Amiri) وإنجليزية (Inter, Arial) مع ألوان وأحجام مختلفة.
  * إضافة أشكال هندسية وقلوب.
  * لوحة طبقات (Layers Panel): ترتيب، قفل، حذف، وإخفاء.
  * تراجع وإعادة (Undo / Redo).

---

### 3. مخرجات الطباعة الصناعية (100% Print-Ready Output)
عند إنهاء أي طلب، يُولّد النظام تلقائياً على السيرفر:
1. **ملف PDF/X-4 عالي الدقة (300 DPI CMYK):**
   * بالمقاس الحقيقي بالملليمتر + الـ Bleed (3 مم).
   * علامات القص الاحترافية (Crop Marks) عند حدود المقاس الصافي.
   * طبقة فكتور لخط القص (CUT Overlay) بلون Spot Magenta (#EC008C).
2. **نسخة PNG بدقة 300 DPI:**
   * بخلفية شفافة بالمقاس الفعلي للبكسلات مع بيانات كثافة الطباعة المدمجة (`density: 300`).
3. **ملف داي لاين فكتور للقص الليزر (CUT Vector SVG):**
   * مسارات متجهة نقية (Vector Paths) بوحدات الملليمتر جاهزة لماكينات الليزر والكاتر بلوتر (Laser Cutters / Plotters).
4. **بطاقة تشغيل الطلب (Job Ticket Slip):**
   * ملف تفصيلي باسم الموديل، الأكواد البديلة، المقاسات الدقيقة، التاريخ، رقم الطلب، وبيانات شهادة اجتياز الـ Preflight.
5. **فحص الـ Preflight الإلزامي قبل التصدير:**
   * يرفض التصدير إذا وُجد خطأ جسيم ويشرح السبب باللغة العربية بوضوح.

---

### 4. لوحة تحكم كاملة للمشرف (Admin Dashboard)
- **إضافة وتعديل الموديلات يدوياً:** إدخال المقاسات بالملليمتر وتحديد الفتحات مع معاينة مباشرة على الشاشة قبل الحفظ.
- **محلل داي لاين SVG من المورد (SVG Die-line Extractor):**
  * رفع ملف SVG المستلم من المورد واستخراج الحدود الخارجية والفتحات الدائرية والمستطيلة وتحويلها لإحداثيات بالملليمتر تلقائياً.
  * معاينة بصرية للداي لاين وربطه بالموديل المستهدف بضغطة زر.
- **استيراد جماعي (Bulk Import):** رفع ملفات CSV أو JSON لمئات الموديلات دفعة واحدة.
- **سجل الطلبات والإنتاج:** استعراض طلبات العملاء وتحميل ملفات الـ PDF والـ PNG والـ SVG فوراً.

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. تشغيل وضع التطوير
npm run dev

# 3. بناء وتشغيل الإنتاج
npm run build
npm run start
```

الموقع يعمل افتراضياً على: `http://localhost:3000`
- الصفحة الرئيسية واختيار الموديل: `http://localhost:3000/`
- لوحة التحكم: `http://localhost:3000/admin`
